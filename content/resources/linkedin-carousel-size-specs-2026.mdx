If your LinkedIn carousel looks blurry, gets cut off, or fails to upload, the problem is usually the specs. Here is the exact LinkedIn carousel size and format that works in 2026.

## Key takeaways

- Use 1080 x 1080 px square slides for the safest result.
- Upload as PDF if you want multiple slides in one post.
- LinkedIn supports PNG and JPG, but PDF gives the carousel behavior.
- Keep slide text large: 32 pt minimum for body copy.

---

## LinkedIn carousel specs at a glance

| Spec | Recommended value | Why it matters |
|---|---|---|
| Dimensions | 1080 x 1080 px | Square looks best on mobile and desktop |
| Aspect ratio | 1:1 | Avoids cropping on all devices |
| File type | PDF | Creates the swipeable carousel effect |
| File size | Under 100 MB | LinkedIn upload limit |
| Slide count | 5–12 slides | Enough depth, not too long |
| Font size | 32 pt minimum | Readable on mobile |
| Margin | 60 px on each side | Prevents text from touching edges |

---

## Why PDF beats image files for carousels

LinkedIn treats a PDF upload as a document carousel. Each page becomes a swipeable slide.

- PNG/JPG carousel: LinkedIn sometimes compresses heavily and crops edges.
- PDF carousel: keeps fonts sharp, layout stable, and formatting consistent.

For best results, export your carousel as a PDF with each slide as a separate page.

## Slide count and engagement

| Slide count | Best for |
|---|---|
| 3–4 slides | Quick tips, announcements |
| 5–7 slides | How-to, list posts, frameworks |
| 8–12 slides | Deep tutorials, case studies, data breakdowns |
| 12+ slides | Use only when the content is highly valuable |

More slides do not mean more engagement. Completion rate drops after 12 slides.

## Font, color, and accessibility

| Element | Recommendation |
|---|---|
| Font | Sans-serif: Inter, Roboto, or system fonts |
| Heading size | 48–64 pt |
| Body size | 32–40 pt |
| Line count per slide | 3–5 lines maximum |
| Color contrast | WCAG AA standard minimum |
| Alt text | Add to any images for accessibility |

---

## Common mistakes to avoid

1. **Wrong aspect ratio** — 16:9 slides get cropped on mobile.
2. **Tiny text** — anything under 28 pt is hard to read.
3. **No margins** — text touching the edge looks unprofessional.
4. **Too many slides** — completion drops after 12.
5. **No final CTA slide** — always tell the reader what to do next.

## FAQ

### What is the best LinkedIn carousel size in 2026?
1080 x 1080 pixels with a 1:1 aspect ratio.

### Should I upload a PDF or image for a LinkedIn carousel?
Use PDF for multi-slide carousels. It creates the swipeable document format.

### What is the maximum slide count for a LinkedIn carousel?
LinkedIn allows up to 300 pages in a PDF document, but 5–12 slides is the engagement sweet spot.

### Can I use 16:9 slides for LinkedIn carousels?
You can, but 1:1 square slides display best on mobile without cropping.

### What font size is readable on mobile?
Use 32 pt minimum for body text and 48–64 pt for headings.
